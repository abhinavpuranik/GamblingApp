# Gambling App

A Python-based gambling and betting simulation application that models betting sessions, stake management, probability-based outcomes, and bankroll tracking.

## Features

- Betting session simulation
- Dynamic stake management
- Win/Loss streak tracking
- Probability-based game outcomes
- Detailed betting logs
- Configurable betting limits
- Object-oriented design using Python classes
- Modular project structure

## Tech Stack

- Python 3
- Object-Oriented Programming (OOP)

## Project Structure

```bash
GamblingApp/
├── main.py
├── models/
├── services/
├── utils/
├── strategies/
└── README.md
```

## Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd GamblingApp
```

Run the application:

```bash
python main.py
```
